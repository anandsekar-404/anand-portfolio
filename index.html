Cybersecurity Chrome Extension
TrustLink
Live on Chrome Web Store

TrustLink is a privacy-focused Chrome extension designed to help users make safer decisions before visiting potentially dangerous websites. It analyzes URLs, detects suspicious links and patterns, calculates risk scores, and warns users about potential threats.

Key Features

  • URL analysis
  • Suspicious link detection
  • Risk scoring system
  • Phishing keyword detection
  • Suspicious URL pattern detection
  • Pre-visit warnings
  • Dangerous site blocking

Technologies

  • HTML5
  • CSS3
  • JavaScript (ES6+)
  • Chrome Extensions API
  • Manifest V3
  • Chrome Storage API
  • Firebase
  • Cloud Firestore
  • Node.js
  • Custom .mjs test files

Security Approach

  • Custom heuristic-based URL analysis
  • Phishing keyword detection
  • Suspicious pattern detection
  • Risk scoring
  • Dangerous site detection & blocking
